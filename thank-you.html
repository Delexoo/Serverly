How to claim your Discord server layout

Serverly delivers a blueprint (channels, categories, roles, and setup notes) — not a Discord account and not automatic bot installs. You create or reset the server in Discord, then apply the layout we send.

  1. Watch your email for Stripe’s receipt and invoice link, plus our order summary with your wizard choices.
  2. In the Discord app, create a new server or use an empty / reset server you’re ready to structure. You stay the owner — we never need your password.
  3. Wait for delivery on your package timeline. We’ll send the full layout document (or agreed format) to the same email you paid with, unless we contact you for a different address.
  4. Implement the blueprint: add categories, channels, and roles to match the guide. Treat it like a detailed template — copy names and structure, then tweak for your community.
  5. Optional: pin rules, welcome copy, and bot invites using the notes we include. Live hands-on fixes aren’t part of this package unless offered separately.
